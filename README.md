# E-Commerce Sales Analytics Dashboard

## Project Overview
This project analyzes e-commerce sales performance using Power BI.  
The dashboard provides insights into revenue, orders, average order value, products sold, monthly performance, and customer distribution.

## Dashboard Preview

![Dashboard](Screenshot%202026-09-22%20223750.png)

## Key Insights
- Track total revenue and compare it with the previous month.
- Monitor total orders and monthly growth.
- Analyze Average Order Value (AOV).
- Track the number of products sold.
- Compare monthly product performance.
- Analyze product categories and customer distribution.

## Tools Used
- Power BI
- Power Query
- DAX
- Data Visualization
- Data Analysis

## Dashboard Features
- Interactive month slicer
- KPI cards with month-over-month comparison
- Conditional formatting for growth rates
- Monthly performance trends
- Product category analysis
- Customer and country analysis
